# Lesson 2 - What is Linux?

## What is Linux?

Linux is the kernel of an operating system.

The kernel manages:

- CPU
- Memory
- Hardware
- Processes
- Networking

---

## Who Created Linux?

Linus Torvalds

Released the Linux kernel in 1991.

----

## What is GNU?

GNU provides many tools that work together with the Linux kernel to form a complete operating system.

Examples include:

- Bash
- GCC
- Core utilities

---

## What is a Linux Distribution?

A Linux distribution combines:

- Linux kernel
- GNU tools
- Additional software

Examples:

- Ubuntu
- Debian
- Fedora
- Arch
- Kali

---

## Why Kali Linux?

Kali Linux is designed for penetration testing and security research.

It includes many security tools, but it is only one Linux distribution.

---

## What I Learned

- Linux is the kernel, not the entire operating system.
- GNU and Linux work together.
- Different Linux distributions are designed for different purposes.
