# Lesson 1 - Boot Process

## Objective

Understand what happens when a computer starts.

---

## Key Terms

### BIOS/UEFI

- Starts the computer.
- Checks hardware.
- Looks for a bootable device.

---

### POST

Power-On Self-Test.

Checks whether:

- RAM works
- CPU works
- Storage is detected

---

### Bootloader

A small program whose job is to load the operating system's kernel.

---

### Kernel

The core of the operating system.

Responsible for:

- CPU
- RAM
- Devices
- Storage
- Networking
- Processes

---

## Boot Sequence

1. Power Button
2. BIOS/UEFI
3. POST
4. Bootloader
5. Kernel
6. Operating System
7. Login Screen

---

## Why This Matters

Understanding the boot process helps explain how a computer starts and provides a foundation for understanding Linux and cybersecurity.
